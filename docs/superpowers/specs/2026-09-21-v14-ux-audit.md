# v14 UX Audit (P48)

Scope walked in code: Chat (`ChatBoxOptimized`, `MessageList`, `MessageInput`, `MemoryPanel`, stream/error paths), Dashboard (`Dashboard`, sidebar), Documents/RAG modal (`DocumentModal`, `DocumentListItem`), Settings/catalog (`Settings`, `ModelCatalog`).

| id | surface | sev | polish | problem | proposed fix |
|----|---------|-----|--------|---------|--------------|
| U1 | Chat | M | yes | `MessageInput` disables submit when message is empty and no file attachments, but ignores `attachedImage`; image-only prompts are blocked. | Include `attachedImage` in submit-enable logic so vision-only requests can be sent. |
| U2 | Chat | M | yes | Multiple icon-only controls rely on `title` (`attach image/file`, `mic`, remove attachment/image) and miss explicit `aria-label`. | Add clear `aria-label` values for every icon-only action button. |
| U3 | Chat | L | no | Empty chat copy says "choose AI role", but this surface does not expose a role picker; copy is misleading. | Update empty-state text to reflect current controls (model/provider, docs, prompt). |
| U4 | Chat | L | yes | Stream stop control is labeled `Stop` (EN) while surrounding UI is UA; action outcome after abort is implicit. | Localize label and show explicit feedback (toast/inline note) when generation is stopped. |
| U5 | Chat / errors | M | yes | Error alert prints raw stream/fallback error strings and offers only dismiss; no recovery CTA. | Map common failures to user-friendly copy and add quick actions (`Retry`, `Check settings`). |
| U6 | Chat / MemoryPanel | L | yes | Memory panel mixes EN/UA microcopy (`Summary`, `Notes`, `Summary ще порожній`, `Нова note`) hurting scanability. | Normalize memory microcopy to one locale and consistent terminology. |
| U7 | Dashboard sidebar | L | no | Initial loading state is spinner-only, no textual status for screen readers or low-context users. | Add short loading text and `aria-live` around loading region. |
| U8 | Documents/RAG modal | M | yes | Per-document delete action is icon-only (`🗑`) without contextual `aria-label`; ambiguous for assistive tech. | Add `aria-label` with filename context (e.g., "Видалити файл <name>"). |
| U9 | Documents/RAG modal | M | no | Pending/failed docs are non-selectable, but reason is only implicit in tiny metadata; actionability is not obvious. | Promote status to clear badge/helper text near checkbox and explain why selection is disabled. |

Polish shortlist for this wave (<=6): U1, U2, U4, U5, U6, U8.
