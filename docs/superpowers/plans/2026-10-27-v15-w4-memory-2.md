# v15 Wave 4 — Memory 2.0 (Cross-Conversation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** User-scoped memory notes that inject into every chat prompt (with caps), CRUD API + Settings UI, tests + one cross-conversation E2E.

**Architecture:** Mirror `conversationMemoryService` patterns with a new `UserMemoryNote` Prisma model and `userMemoryService`. Mount REST under `/api/users/me/memory-notes`. Inject via `buildUserMemorySystemMessages(userId)` inside `buildSystemContext` **before** conversation memory. UI: single card on Settings page. Failures are best-effort (log + continue chat).

**Tech Stack:** Prisma migrate, Express, Jest, React Query/hooks, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-27-project-evolution-roadmap-v15-design.md` §7  
**Prerequisite:** Wave 3 gate green on `master`.

## Global Constraints

- Caps: `MAX_USER_NOTES = 30`, `MAX_USER_NOTE_CHARS = 500`, `MAX_USER_NOTES_PROMPT_CHARS = 2000` (export constants).
- Prompt order (fixed): **user notes → conversation summary → conversation notes → RAG**.
- No vector LTM, no auto-extract, no multi-profile personas.
- Ownership: `userId` only; 404 on missing note for other users.
- User-memory fetch errors must not 500 the stream path.

```ts
export async function buildUserMemorySystemMessages(
  userId: number
): Promise<ChatMessage[]> {
  const notes = await prisma.userMemoryNote.findMany({
    where: { userId },
    orderBy: { createdAt: 'asc' },
    select: { content: true },
  });
  if (notes.length === 0) return [];
  const prefix = "👤 НОТАТКИ КОРИСТУВАЧА:\n\n";
  const body = notes.map((n) => `- ${n.content}`).join('\n');
  const maxBody = Math.max(0, MAX_USER_NOTES_PROMPT_CHARS - prefix.length);
  return [
    {
      role: 'system',
      content: `${prefix}${body.length > maxBody ? body.slice(0, maxBody) : body}`,
    },
  ];
}
```
