# v15 Wave 1 — P49 E2E / CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Docker Playwright E2E reliably green for citation, memory, settings round-trip, and hardened stream — including CI auth/login.

**Architecture:** Specs already exist under `e2e/`. Fix env plumbing so registration/login works in compose CI, harden `loginViaUi`, then run the four P49 specs against `docker compose` and fix only what fails. No Electron Playwright.

**Tech Stack:** Playwright (`e2e/`), Docker Compose, GitHub Actions `e2e-smoke.yml`, Express auth (`ALLOW_REGISTRATION`).

**Spec:** `docs/superpowers/specs/2026-10-27-project-evolution-roadmap-v15-design.md` §4

## Global Constraints

- Skip with explicit reason only — never silent pass.
- Prefer resilient selectors; add `data-testid` only where brittle.
- Do not add Electron E2E.
- Do not make “LLM unavailable” a hard CI failure policy.
- Keep existing skip-when-RAG/LLM-missing behavior for citation/memory/stream LLM-dependent asserts.
- Auth/register path must not skip in default CI compose.

(Place near `NODE_ENV`.)

(Uncomment or set explicitly for local E2E.)

- [ ] **Step 3: Harden CI workflow env**

In `.github/workflows/e2e-smoke.yml`, change Start Docker stack to write the var into `.env` and set E2E API URL on the test step:

```yaml

          cp .env.example .env

        working-directory: e2e
        env:
          E2E_BASE_URL: http://localhost:3000
          E2E_API_URL: http://localhost:5000
```

```tsx

```

- [ ] **Step 2: Update `loginViaUi`**

Replace body of `loginViaUi` in `e2e/test-helpers.ts`:

```ts
export async function loginViaUi(page: Page, user: TestUser): Promise<void> {
  await page.goto('/login');
  await page.getByTestId('login-email').fill(user.email);
  await page.getByTestId('login-password').fill(user.password);
  await page.getByTestId('login-submit').click();
  await expect(page).toHaveURL(/\/dashboard/, { timeout: 20_000 });
}
```
