# v16 Wave 2 — RAG Performance & Token/Cost Telemetry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Accelerate RAG chat preparation latency through parallel execution, extract and persist token usage and estimated cost ($ USD) across OpenAI, Gemini, and Ollama providers, and display a subtle telemetry badge under assistant messages.

**Architecture:**
Update Prisma schema to add `tokenUsage Json?` to the `Message` model with a database migration. Implement a modular `tokenCostCalculator.ts` utility mapping standard model families to pricing. Update provider streaming adapters (`openaiService`, `geminiService`, `ollamaService`) to collect stream usage metadata and emit a new `token_usage` SSE event before `done`. Parallelize message history loading and system/RAG context preparation in `prepare.ts` via `Promise.all`. Update `useChatStream` and `MessageItem` to display an accessible token count and cost badge with a visibility toggle in `GeneralSettingsTab`.

**Tech Stack:** Express, Prisma, PostgreSQL (JSONB), OpenAI SDK, Google GenAI SDK, Ollama API, React 18, TanStack Query, Vitest, Jest.

- [ ] **Step 2: Implement `backend/src/utils/tokenCostCalculator.ts`**

```typescript
interface ModelPricing {
  promptPerMillion: number;
  completionPerMillion: number;
}

const PRICING_MAP: Record<string, ModelPricing> = {
  // OpenAI
  'gpt-4o-mini': { promptPerMillion: 0.15, completionPerMillion: 0.60 },
  'gpt-4o': { promptPerMillion: 2.50, completionPerMillion: 10.00 },
  'gpt-3.5-turbo': { promptPerMillion: 0.50, completionPerMillion: 1.50 },

  // Google Gemini
  'gemini-2.0-flash': { promptPerMillion: 0.10, completionPerMillion: 0.40 },
  'gemini-2.0-flash-exp': { promptPerMillion: 0.10, completionPerMillion: 0.40 },
  'gemini-1.5-flash': { promptPerMillion: 0.075, completionPerMillion: 0.30 },
  'gemini-1.5-pro': { promptPerMillion: 1.25, completionPerMillion: 5.00 },

  // Anthropic Claude (ready for Wave 4)
  'claude-3-5-sonnet-20241022': { promptPerMillion: 3.00, completionPerMillion: 15.00 },
  'claude-3-5-haiku-20241022': { promptPerMillion: 0.80, completionPerMillion: 4.00 },
};

export function calculateTokenCost(
  model: string,
  promptTokens: number,
  completionTokens: number
): number | undefined {
  const normalized = model.toLowerCase().trim();
  
  if (normalized.startsWith('ollama') || normalized.includes(':') || normalized.startsWith('llama') || normalized.startsWith('mistral') || normalized.startsWith('qwen') || normalized.startsWith('phi')) {
    return 0;
  }

  // Exact match or prefix match
  let pricing: ModelPricing | undefined = PRICING_MAP[normalized];
  if (!pricing) {
    const key = Object.keys(PRICING_MAP).find((k) => normalized.includes(k));
    if (key) pricing = PRICING_MAP[key];
  }

  if (!pricing) return undefined;

  const promptCost = (promptTokens / 1_000_000) * pricing.promptPerMillion;
  const completionCost = (completionTokens / 1_000_000) * pricing.completionPerMillion;
  const total = promptCost + completionCost;
  return Math.round(total * 1000000) / 1000000;
}
```
